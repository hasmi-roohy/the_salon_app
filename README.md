# The Salon App

Flutter salon application with local virtual try-on for hairstyles, beards,
and nail art.

## Run Flutter App

```powershell
flutter pub get
flutter run
```

## Validate

```powershell
flutter analyze
flutter test
```

## Optional Backend

```powershell
npm install
npm run build
npm run start
```

The AR Mirror preview runs locally and does not require the backend.
